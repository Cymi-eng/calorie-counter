#  Calorie Counter

## Overview

A JavaScript-based calorie tracking application that allows users to add, remove, and manage daily food intake while calculating total calories consumed.

## Features

* Add food items
* Remove food items
* Calculate total calories
* Reset daily records
* Persist data using localStorage
* Fetch API demonstration
* Responsive Tailwind CSS interface

## Technologies Used

* HTML5
* Tailwind CSS
* JavaScript
* DOM Manipulation
* LocalStorage
* Fetch API

## Installation

1. Clone the repository

```bash
git clone https://github.com/cymi-eng/calorie-counter.git
```

2. Open `index.html` in your browser
