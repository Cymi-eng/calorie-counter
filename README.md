#  Calorie Counter

## Overview

A webpage calorie tracking application that allows users to add, remove, and manage daily food intake while calculating total calories consumed.

## Features

* Add food items
* Remove food items
* Calculate total calories
* Reset daily records
* Persist data using localStorage
* Fetch API demonstration
* Responsive Tailwind CSS interface

## Technologies Used

* HTML5
* Tailwind CSS
* JavaScript
* DOM Manipulation
* LocalStorage
* Fetch API

## Installation

1. Clone the repository

```bash
git clone https://github.com/cymi-eng/calorie-counter.git
```
2. Navigate to the Project Folder

cd calorie-counter

3. Open `index.html` in your browser

# How to Use
1. Enter a food name.
2. Enter its calorie value.
3. Click Add Food.
4. The food item appears in the list.

# Removing Food
1. Locate the food item.
2. Click the Delete button.
3. The item is removed and the total calories update automatically.
# Resetting
1. Click the Reset button.
2. All food items are cleared.
3. Total calories return to zero
